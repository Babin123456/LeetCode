## 🚀 How to Use

- Run Python solutions:

```bash
python "<filename>.py"
```

- Compile and run a C++ file (MinGW / g++ example):

```bash
g++ -std=c++17 -O2 "1536. Minimum Swaps to Arrange a Binary Grid.c++" -o main.exe
./main.exe
```

Replace the filename as needed. On Windows use the appropriate `g++` executable path or Visual Studio `cl.exe`.

## 💡 VS Code C/C++ IntelliSense (squiggles)

If you see include errors like `could not open source file "vector"`, configure the C/C++ extension:

- Open Command Palette → `C/C++: Select a Configuration...` and pick your compiler (MSVC, MinGW, WSL).
- Or create `.vscode/c_cpp_properties.json` with correct `compilerPath` and `includePath` entries so system headers are discovered.

Example snippet (adjust `compilerPath`):

```json
{
 "configurations": [
  {
   "name": "Win32",
   "compilerPath": "C:/mingw64/bin/g++.exe",
   "intelliSenseMode": "gcc-x64",
   "includePath": ["${workspaceFolder}/**", "C:/mingw64/include"]
  }
 ],
 "version": 4
}
```
